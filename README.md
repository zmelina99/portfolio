# Meli Zellweger — Portfolio

My personal portfolio site. I'm an Implementation & Solutions Engineer, and the site covers my experience, case studies, projects, skills and how to reach me.

It has an ocean-dive theme: a depth gauge tracks how far you've scrolled down the page. The site is available in English, Spanish and French.

## Built with

- Next.js 15 and React 19
- TypeScript
- Tailwind CSS 4
- Vercel Analytics

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
